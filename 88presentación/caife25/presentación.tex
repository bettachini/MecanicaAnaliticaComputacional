\begin{frame}
	\frametitle{Una competencia fundamental para el mecánico}
	\begin{block}{Mecánica computacional}
		\begin{itemize}
			\item Simplificación de dispositivos como conjunto de cuerpos rígidos $\rightarrow$ modelo matemático.
			\item Euler-Lagrange $\rightarrow$ ecuaciones diferenciales de esfuerzos y dinámica.
			\item Cálculo numérico $\rightarrow $ gráficas y magnitudes límites para orientar el diseño.
		\end{itemize}
	\end{block}
	\pause
	\begin{block}{El alumno ``construye" su competencia}
		Papert (1980) ``El mejor aprendizaje tiene lugar cuando el sujeto toma el mando''
		\pause
		\begin{itemize}[<+->]
			\item Problemas de ejemplo se resuelven con el código provisto por el profesor
			\item El estudiante lo \textbf{recicla} para resolver los de la guía de ejercicios
			\item Gradualmente adquiere autonomía y genera su propio código.
			\item Finalmente, puede aprovecharse de la IA para acelerar su trabajo.
			\item Tras aprobar la asignatura conserva su repositorio con todo su código.
		\end{itemize}
	\end{block}
\end{frame}
